/* THE MODEL */

February 2026: Shifted from always-on to on-demand agent spawning.

OLD MODEL (Pre-Feb 2026):
- Agents ran continuous heartbeats every 15-30 minutes
- 24/7 operation, always consuming resources
- Cost: ~£140/week
- Complex coordination, idle time

NEW MODEL (Current):
- Zak coordinates 24/7, spawns agents only when needed
- Agents run for specific tasks (3-8 minutes), then stop
- Cost: ~£28/week (90% reduction)
- Simpler coordination, no idle waste

How it works:
1. Task identified (research needed, content required, etc.)
2. Zak spawns appropriate specialist agent
3. Agent completes task, reports back
4. Agent shuts down, resources released
5. Zak reviews and delivers to Thomas

Current metrics:
- 90% cost reduction vs. always-on model
- 6 specialist agents available
- 24/7 coordination via Zak
- Average task completion: 3-8 minutes
- Same capabilities, fraction of the cost
